# Learning Cronogram (5 Weeks)

## Week 1: OAuth2/OIDC Foundations
- OAuth2 roles and flows; JWT vs opaque tokens.
- OIDC discovery and JWKS.
- Build a minimal Spring Security resource server.

## Week 2: Azure Identity + Angular Integration
- Entra ID/B2C app registrations, scopes, roles.
- MSAL Angular setup with Authorization Code + PKCE.
- Claims mapping and JWT validation in Spring.

## Week 3: Service-to-Service Security
- Client Credentials flow for internal services.
- On-Behalf-Of flow for downstream APIs.
- Audit logging and token tracing.

## Week 4: Containers + Kubernetes
- Dockerize Spring Boot and Angular.
- AKS basics, Helm/Kustomize deployment.
- Secrets with Key Vault + CSI Driver.

## Week 5: Terraform + Azure Provisioning
- Terraform state, variables, and modules.
- Provision AKS, ACR, Key Vault, and Static Web Apps.
- CI/CD pipeline design for build and deploy.
